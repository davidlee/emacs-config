# File Manager — Dired / Dirvish / Yazi / Broot

Single coherent file-management story, anchored on Dired with Dirvish as the
UI, escape hatches to Yazi and Broot via ghostel, and consult/project for
search-driven navigation. Implemented 2026-05-16.

## Shape

- **Dired is the substrate.** Dirvish overlays it via
  `dirvish-override-dired-mode`; its `nerd-icons` attribute provides icons.
- **Yazi / Broot run as the real CLIs** in a ghostel terminal. On exit, a
  process sentinel reads a temp file (Yazi's `--cwd-file`, Broot's
  `--outcmd`) and opens the result in Dired, then kills the ghostel buffer.
- **`my-file-map` (`C-c f`) is the single home** for file ops + navigation.
  Mirrored automatically onto `SPC f` via Meow's leader.

## Keymap — `my-file-map` (`C-c f` / `SPC f`)

| Key | Command                  |
| --- | ------------------------ |
| `f` | `find-file`              |
| `s` | `save-buffer`            |
| `S` | `write-file`             |
| `r` | `consult-recent-file`    |
| `d` | `dired-jump`             |
| `D` | `dirvish`                |
| `t` | `dirvish-side` (tree)    |
| `F` | `project-find-file`      |
| `p` | `project-switch-project` |
| `y` | `my/yazi-here`           |
| `b` | `my/broot-here`          |

Globals: `C-x C-j` → `dired-jump`, `C-x C-n` → `dirvish-side`. `C-x C-q`
in Dired still drops to `wdired-change-to-wdired-mode` (built-in).

## Files

- `apps/dl-dired.el` — Dired core (`:ensure nil`), `diredfl`, `nerd-icons`,
  `ready-player`. Trash on delete, recursive copy, group-dirs-first listing,
  `dired-find-alternate-file` enabled so `dirvish-side` can auto-close.
- `apps/dl-dirvish.el` — Dirvish config + the `my/yazi-here` / `my/broot-here`
  wrappers and shared `my/file-manager--launch` helper.
- `core/dl-keymap.el` — `my-file-map` entries + the two `C-x` globals.
- `editing/dl-project.el` — `project` + `diredfl`. (`dired-subtree` retired;
  Dirvish's `dirvish-subtree-toggle` on `TAB` supersedes it.)
- `editing/dl-persist.el` — autosave / saveplace / vundo. (Duplicate
  `recentf` block dropped; canonical lives in `completion/dl-completion.el`.)
- `init.el` — `(require 'dl-dired)` and `(require 'dl-dirvish)`. Without
  these the wrapper `defun`s never load and `C-c f y/b` errors with
  `commandp` on an unbound symbol.

## Yazi / Broot wrappers

`my/file-manager--launch` is the shared shape (same as `apps/dl-shpool.el`'s
`ghostel-exec` pattern):

1. Pick a starting directory — the visited file's directory if any, else
   `default-directory`.
2. `pop-to-buffer` a `*yazi:DIR*` / `*broot:DIR*` buffer and `ghostel-exec`
   the CLI with its temp-file flag.
3. Attach a process sentinel. On `finished`/`exited`:
   - Read and `delete-file` the temp file.
   - Kill the ghostel buffer (`kill-buffer-query-functions` suppressed).
   - Call the handler with the trimmed contents.

**Yazi** — `--cwd-file TMP` writes the final cwd; handler `dired`s it.

**Broot** — `--outcmd TMP` writes a shell command (default `:cd PATH`).
`my/broot--parse-outcmd` extracts the path (handles bare, double- and
single-quoted). Use **alt-enter** in broot to fire the `:cd` verb.

## What got dropped

- `dired-preview` — Dirvish provides previews.
- `dired-sidebar` — `dirvish-side` replaces.
- `nerd-icons-dired` — Dirvish's `nerd-icons` attribute already paints icons;
  running both produced visible double icons. Removed from `apps/dl-dired.el`
  *and* `core/dl-interface.el` (the inventory missed the second copy).
- `dired-subtree` — `dirvish-subtree-toggle` on TAB.
- Duplicate `recentf` in `editing/dl-persist.el`.
- `("C-c f" . dirvish-dwim)` in `apps/dl-dirvish.el` — shadowed the prefix.

`custom-vars.el`'s `package-selected-packages` still lists some of the
above; it's autogenerated and not load-bearing under Nix (no MELPA at
runtime). Left for organic cleanup.

## Traps hit during implementation

- **`lexical-binding` on line 2.** The file-local-variable line must be on
  line 1; if it's on line 2 the cookie is silently ignored and the file
  loads with dynamic scoping. The sentinel lambda then doesn't close over
  `on-exit-file` / `on-exit-handler` and fails with `void variable` when
  the process exits.
- **Missing `require` in `init.el`.** `dirvish` autoloads brought up
  `dirvish` itself, but `my/yazi-here` / `my/broot-here` are plain `defun`s
  and need their file loaded explicitly. Without it the keymap entry
  resolves to an unbound symbol and dispatch raises `commandp`.
- **`broot --out` does not exist** — the flag is `--outcmd`, and it writes
  a shell command, not a bare path. A small regex parser bridges the gap.
- **Ghost buffer after yazi exits.** Default `ghostel-exec` leaves the
  buffer alive with a dead process. Sentinel now kills it.
