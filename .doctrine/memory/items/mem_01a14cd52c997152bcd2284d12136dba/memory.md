gptel's backend URL is protocol://host + endpoint; there is no :port slot. `(url-host (url-generic-parse-url "http://127.0.0.1:4000/v1"))` returns "127.0.0.1" (port dropped; verified in emacs -Q). So any base-URL → backend split must format "host:port" into :host — see `dl-gptel--gateway` in apps/dl-gptel.el (SL-015 PHASE-02). No ert test loads apps/dl-gptel.el, so a regression here only shows at a live request.
