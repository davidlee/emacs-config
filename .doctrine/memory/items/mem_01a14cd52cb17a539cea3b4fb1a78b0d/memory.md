`just check` runs batch ERT without package autoloads, so autoloaded constructors like `gptel-make-deepseek` (gptel-openai-extras.el) are void. A test that builds a real `gptel-deepseek` backend must `(require 'gptel-openai-extras)` — as lisp/test/dl-gptel-presets-test.el does. Symptom otherwise: the file fails to load and `just check` reports only a one-line LOADERR with no backtrace.
